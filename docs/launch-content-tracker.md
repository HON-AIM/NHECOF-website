# NHECOF Launch Content Tracker

> **Purpose:** one register of everything that must exist before the website
> launches, who is responsible, and what evidence is outstanding.
>
> **Source of the targets:** `CLAUDE.md` §18 Phase 9 (Content Population and
> Review) and §22 (Immediate Pre-Build Checklist).
>
> **Nothing in this file is content.** Topic, owner and reviewer fields are
> deliberately empty. They are filled in by NHECOF, not by anyone preparing the
> project. A blank cell means "not yet decided or not yet assigned", never
> "assume it is fine".

---

## How to use this file

1. Add a row when a topic is agreed, and fill in **Owner** and **Reviewer** the
   same day.
2. Move **Status** as the work progresses.
3. **Sources verified** and **Images cleared** are evidence columns. They are not
   ticked optimistically. A tick means somebody opened the source and it said
   what the content claims.
4. Update this file at the weekly review meeting.
5. When everything is done, archive it with the launch record.

### Status key

| Status | Meaning |
| --- | --- |
| `not started` | Topic not yet chosen or not yet begun |
| `assigned` | Owner and reviewer agreed, no drafting yet |
| `drafting` | First draft in progress |
| `in review` | Submitted to a qualified reviewer |
| `revising` | Reviewer sent it back |
| `approved` | Reviewer approved; not yet published |
| `published` | Live on the website |
| `blocked` | Cannot progress — see the note |

### Evidence column key

| Value | Meaning |
| --- | --- |
| `—` | Not started / not applicable |
| `pending` | Claimed, not yet checked |
| `partial` | Some sources checked, others outstanding |
| `verified` | **Every** factual claim traced to a source that was read and supports that claim |
| `n/a` | No images used for this item |

> **Rule for the two evidence columns.** `sources verified` and `images cleared`
> may only read `verified` / `cleared` when a named person has confirmed it. If
> the person who wrote the item also ticked its own evidence column, that is
> acceptable for sources but **not** for images — image clearance is confirmed
> by the outreach manager.
